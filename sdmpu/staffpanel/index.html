Type what you want to do, for example: issue, return, overdue, reserve, hide page, award, photo.

👁 Manage Tabs

Tick = the page shows on the website for everyone. Untick to hide it. It changes at once, no deploy needed.

💾 Code Backup

See and copy the current code of these website pages. The Apps Script files are kept in the Apps Script projects (script.google.com).

👤 Member Lookup

Search by Lib ID or name to see the books the member holds now.

📋 Manage Book Reservations

Reservations made on My Library and at the counter. "Kept aside" e-mails the member that the book is ready.

📥 Bulk Issue

Write LibID:AccNo, one per line or comma separated. Example: 252614994:1018, 252614995:2210

📤 Bulk Return

Accession numbers, comma or new line. Example: 1018, 2210

🗑 Bulk Discard

Accession numbers to write in the Decard Books register. Example: 188, 228

⏰ Overdue Books

Every book still issued after its due date, the oldest first.
