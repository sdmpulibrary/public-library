Batch settings / ಈ ಗುಂಪಿನ ಸಾಮಾನ್ಯ ವಿವರ

These are the same for all the books of one bill or one donation. Set them once. The Acc Nos are given when you submit the batch.

Add one book / ಪುಸ್ತಕ ಸೇರಿಸಿ

Photograph in this order: cover, details page (publisher, price, ISBN), one or two introduction / contents pages, back cover with the author photo. You can skip any photo. Put a dark sheet behind a thin page. You check the whole batch later.

Photo basket / ಫೋಟೋ ಬುಟ್ಟಿ

Take photos of many books with the phone camera on a plain dark or plain light background, book after book. Before each new book, photograph the "Next book" card. Then add all the photos here. The page cuts each photo to the book, groups the photos book by book and sends them. The reading is done afterwards by itself - you do not wait.

(print it once, keep it with the camera)
Fixed box: choose one sample photo, then move the sliders until the frame is round the book. The same frame is used for all photos.

After uploading - reading by Gemini

The books are read one after another, even if you close this page. When a book is Ready it is in tab 3 (Verify and submit).

Ready photos / ಸಿದ್ಧ ಫೋಟೋಗಳು

For photos you already took of many books: a PDF of scans, a ZIP, a folder, or many photos. In each book the first photo must be the cover, then the details page, introduction pages and back cover. The page groups the photos book by book; you check the groups in tab 2b and upload them there.

Verify the batch / ಪರಿಶೀಲಿಸಿ

Press Refresh.

Old book / ISBN  ಹಳೆಯ ಪುಸ್ತಕ

Type the Acc No of a book already in the register (for example P-5247). Correct any detail, add a cover photo, or type / scan the ISBN to fill the details. Acc No, Barcode and the status columns are never changed here. Every change is kept in the sheet BOOK_EDIT_LOG (old and new value).

Koha file and covers / Koha ಫೈಲ್ ಮತ್ತು ಮುಖಪುಟಗಳು

1. Koha file (.mrc)

Every submitted book is also in the tab KOHA_MARC of your Google Sheet (one row per copy, the same columns as your Koha sample sheet). Check the Verify column there. Then make the file and load it in Koha: Cataloguing > Stage records for import (framework: Book / Workbook, items: yes).

2. Cover photos ZIP

One picture per Acc No (e.g. P-5247.jpg), each under 20 KB.
